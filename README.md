# 頂琉計畫：琉意健康 綠行琉客

這是一個依照提案 PDF 雛形建立的前後端分離網站系統。前台面向大眾瀏覽，後端提供 REST API，資料存放在 SQLite。

## 架構

- `backend/`: Node.js 原生 HTTP API + SQLite
- `frontend/`: 獨立靜態前端，透過 API 讀取資料
- `backend/data/app.db`: 開發用 SQLite 資料庫，啟動時若不存在會自動建立並 seed

## 啟動

開兩個終端機：

```bash
npm run dev:backend
npm run dev:frontend
```

- 前端：http://localhost:5173
- 後端：http://localhost:4000/api

## 已完成的 MVP 功能

- 碳足跡計算：依起訖景點與交通方式估算排碳量、減碳點數與海龜生命值
- 低碳路線推薦：展示景點與低碳交通資訊
- 海龜養成：以前端互動方式呈現等級、生命值與獎勵
- 永續店家：以資料庫維護在地店家資訊
- 減塑行動指南：以資料庫維護行動項目與點數
- 最新消息與環境教育：以資料庫維護文章列表
